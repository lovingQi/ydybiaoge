# Excel IP地址处理工具 v2.0

一个专业的Excel IP地址处理工具，支持IP地址标准化、重复检测、网段分析等功能。

## 功能特性

### 核心功能
- **IP地址格式标准化**：自动将IP地址转换为标准CIDR格式
- **重复IP检测**：智能检测重复IP并根据运营商规则提供处理建议
- **网段包含关系检测**：检测网段是否包含其他IP地址
- **网段一致性检查**：验证IP地址与网段列的一致性

### 界面特性
- **现代化GUI界面**：基于tkinter的美观用户界面
- **实时日志显示**：所有处理过程实时显示在界面上
- **进度跟踪**：详细的处理进度显示和状态更新
- **历史记录**：保存处理历史，方便查看和管理
- **多线程处理**：后台处理避免界面卡顿
- **取消功能**：支持中途取消正在进行的处理

## 处理规则

### IP地址标准化规则

1. **纯IP格式** (如 `36.134.44.69`) → 添加`/32`后缀
2. **网段格式** (如 `36.134.41.0`) → 添加`/24`后缀
3. **已标准格式** (如 `36.134.205.246/32`, `36.134.41.0/24`) → 保持不变

### 重复IP处理规则

根据运营商信息智能判断处理方式：

1. **相同运营商**：标记删除重复行
2. **运营商包含关系**：
   - 单一运营商被组合运营商包含：删除单一运营商行
   - 组合运营商包含单一运营商：保留组合运营商，删除单一运营商
3. **不同运营商**：保留所有行

### 网段包含关系处理

检测`x.x.x.0/24`格式的网段是否包含其他IP地址，并根据运营商规则提供处理建议。

## 输出文件

程序会生成三个输出文件：

1. **`原文件名_checked.xlsx`**：包含检查结果和标记的文件
2. **`原文件名_processed.xlsx`**：应用处理规则后的中间文件
3. **`原文件名_result.xlsx`**：最终清理后的结果文件

## 常见问题

### Q: 程序启动失败
A: 请确保已安装Python 3.7+和所需依赖库（pandas, openpyxl）

### Q: 处理大文件时程序卡顿
A: 程序使用多线程处理，界面应该不会卡顿。如果出现问题，可以尝试重启程序。

### Q: 如何取消正在进行的处理
A: 点击"取消处理"按钮，程序会安全地停止当前操作。

### Q: 输出文件在哪里
A: 输出文件保存在原Excel文件的同一目录下，文件名会添加相应后缀。
